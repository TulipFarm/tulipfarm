---
title: Install a skill
description: Scan a git repository, review SkillAudit findings, and install selected Skills.
---

This guide installs an existing [Skill](/docs/concepts/skills) from a git repository. The
real install flow is always **scan → SkillAudit → install**.

## Outcome

At the end, selected Skills are copied into the Soul, pinned in `skills-lock.json`, and
available for agents to load on demand.

## Ask where to start

If you know the repository but not which Skills it contains, start in chat:

```prompt
I want to install the Skills from https://github.com/example/acme-skills. Help me
scan them and decide which ones are safe to install.
```

The assistant can explain what to expect. The actual install confirmation happens in the
Skills UI so an operator can review the audit report before anything is installed.

## Scan the repository

<Steps>
  <Step>
    Open **Skills → Marketplace** or **Skills → Install**.
  </Step>
  <Step>
    Enter a git repository URL. A `#branch` suffix is supported when you need a specific
    branch.
  </Step>
  <Step>
    Choose **Scan**. TulipFarm clones the repo, finds installable `SKILL.md` files, and
    shows the discovered Skills.
  </Step>
</Steps>

## Run SkillAudit

Select the Skills you want, then choose **Run SkillAudit**. SkillAudit is an LLM safety
review that summarizes intent, risk, tool guidance, and findings for each selected Skill.

<Callout type="warn">
SkillAudit is advisory. A Skill is natural-language instruction, so read the findings and
source before confirming an install.
</Callout>

## Confirm the install

After every selected Skill has an audit report, choose **Confirm install**. TulipFarm
writes the Skills into the Soul, commits the change, and records the source and content
hash in `skills-lock.json`.

## Verify

Open **Skills**. The installed Skills should appear with their descriptions and
provenance. Ask an Agent to use one only after you are comfortable with the audit result.
