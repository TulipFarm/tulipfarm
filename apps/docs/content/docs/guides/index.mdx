---
title: Guides
description: Task recipes — set up your instance, build with chat, connect the systems you already use, and operate what you have running.
---

Each guide is one task with a stated outcome. If you want the idea behind a task rather than
the steps, read [Concepts](/docs/concepts) instead.

Most guides start with a prompt, because that is genuinely how you build TulipFarm — you
describe what you want and an agent builds it. Guides that configure the instance itself
(secrets, model providers, admin screens) are the exception and stay in the UI.
