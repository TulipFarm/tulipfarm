---
title: Store a secret
description: Add, replace, and delete encrypted write-only secrets from Operate.
---

This guide stores a [Secret](/docs/concepts/secrets) for credentials that TulipFarm or an
Integration needs. Managing secrets requires an admin account.

## Outcome

At the end, the secret key is present in TulipFarm's encrypted secret store, but its value
cannot be read back through the UI or API.

<Steps>
  <Step>
    Open **Operate → Business → Secrets**.
  </Step>
  <Step>
    Under **Configure a provider**, choose a built-in provider or choose **Custom…** for
    a key you name yourself.
  </Step>
  <Step>
    Enter the secret key and value. For example, a custom integration token might use the
    key `stripe-api-key`.
  </Step>
  <Step>
    Choose **Save provider**. TulipFarm encrypts the value before storing it.
  </Step>
</Steps>

<Callout type="warn">
Secret values are write-only. `GET /api/v1/secrets/status` returns keys and metadata,
including whether a value is present, but it never returns plaintext values.
</Callout>

## Replace or delete a secret

To rotate a value, save a new value under the same key. To remove one, choose **Delete**
on its row. Deleting is idempotent: if the key is already gone, the delete still leaves
the store in the desired state.
