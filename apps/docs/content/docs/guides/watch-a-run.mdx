---
title: Watch a run
description: Use the Runs list and Run inspector to follow durable work and control it safely.
---

This guide follows a [Run](/docs/concepts/runs). A Run is a durable execution of chat,
Integration, or Routine work. A Run contains States, waits, effects, Guardrail decisions,
lineage, costs, and a persisted event stream.

## Outcome

At the end, you can inspect a Run, recover from a dropped browser connection, and use the
available controls safely.

## Open the Runs list

<Steps>
  <Step>
    Open **Runs**.
  </Step>
  <Step>
    Select the Run you want to inspect. Chat turns also return an `X-Run-Id`, and Routine
    pages link to their Runs.
  </Step>
</Steps>

## Read the inspector

The Run inspector shows:

- status and Run id
- routine id/version when applicable
- model cost and token count
- States and attempts
- effects and waits
- Guardrail decisions
- lineage

The event stream is durable. If the browser drops, the client reconnects by cursor using
`?after=` or `Last-Event-ID`, so already persisted Run events are not lost.

## Use controls

Use the smallest safe control:

- **pause** stops scheduling new work at a safe boundary.
- **resume** continues a paused Run.
- **retry** starts another attempt when the failure is safe to repeat.
- **reconcile** resolves ambiguous external effects before retrying.
- **cancel** requests cancellation. Stopping a chat turn cancels its Run wherever it is
  executing.

<Callout type="warn">
Reconcile before retrying when an external effect might already have happened. Retrying
without reconciliation can duplicate work outside TulipFarm.
</Callout>

## When a turn misbehaves

<Steps>
  <Step>
    Open the Run inspector and read the failed or waiting State.
  </Step>
  <Step>
    Check **Inbox** for an undecided Approval or human task.
  </Step>
  <Step>
    Open **Settings → Observability** for recent turns, trace drill-down, and cost/usage
    summary.
  </Step>
  <Step>
    Open **Settings → Activities** for the broader activity log.
  </Step>
</Steps>
