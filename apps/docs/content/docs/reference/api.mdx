TulipFarm serves the public API under the real prefix `/api/v1`. On your own instance, the live
OpenAPI document is available at `/api/v1/openapi.json`.

Use a concrete host for your deployment, for example `https://tulipfarm.example/api/v1` or
`http://localhost:4010/api/v1` in local development.

## Authentication

Browsers authenticate with the `tf_sid` session cookie. Mutating browser requests must also echo the
`csrf_token` cookie in the `x-csrf-token` header. Login, logout, invite preview, and invite accept
are the pre-session exceptions.

Scripts can use personal API tokens as bearer credentials. Tokens are created under
`POST /api/v1/auth/tokens`, have the `tulip_` prefix, and are shown only once. See
[Issue an API token](/docs/using-tulipfarm/issue-an-api-token).

```bash
curl -X POST https://tulipfarm.example/api/v1/auth/tokens \
  -H "Content-Type: application/json" \
  -H "Cookie: tf_sid=<session>; csrf_token=<csrf>" \
  -H "x-csrf-token: <csrf>" \
  -d '{"name":"reporting-script"}'

curl https://tulipfarm.example/api/v1/resources/customers \
  -H "Authorization: Bearer tulip_<token>"
```

## Errors

Most error responses are JSON objects with an `error` string. Validation errors may include a
`path` JSON Pointer so clients can attach the message to a field.

| Status | Meaning |
| --- | --- |
| `401` | No valid session cookie, personal API token, or API-client credential was accepted. |
| `403` | The principal is authenticated but not allowed to perform the action. |
| `404` | The requested route or record was not found, or is not visible to this principal. |
| `409` | Concurrency or idempotency conflict, such as a stale write or replayed chat turn. |
| `422` | Request validation failed. Resource validation includes a JSON Pointer `path` when available. |

## Endpoint families

Every route lives under `/api/v1`, apart from the three health checks. The families below are the
OpenAPI tags, and each one is a place to look rather than a list to memorise.

This page deliberately does not list individual endpoints or count them. A hand-typed catalogue
drifts the moment someone adds a route, and a wrong reference page is worse than no reference page.
**For exact paths, parameters, and response shapes, read `GET /api/v1/openapi.json` on your own
instance.** It is generated from the running server, so it is never out of date.

### Talking to agents

| Family | Base path | What it covers |
| --- | --- | --- |
| `chat` | `/chat`, `/chats` | Starting a chat turn, stopping a run, reading history. |
| `feedback` | `/messages/{id}/feedback` | Thumbs up or down on an agent message. |
| `surfaces` | `/surfaces` | Rendered agent output and the interactions people click. |
| `tasks` | `/tasks` | Work an agent handed back to a person: answer, claim, snooze, dismiss. |
| `approvals` | `/approvals`, `/inbox` | Actions an agent paused on until someone decides. |

### What the business knows

| Family | Base path | What it covers |
| --- | --- | --- |
| `resources` | `/resources/{type}` | Reading and writing records. |
| `knowledge` | `/knowledge` | Spaces, pages, revisions, search, and reindexing. |
| `memory` | `/memory` | Scoped agent memory entries. |
| `kv` | `/kv` | The agent key-value store. |
| `kv-admin` | `/admin/kv` | The same store, across every namespace, for admins. |

| `business` | `/business` | Business name, description, and profile. |

### Running the instance

| Family | Base path | What it covers |
| --- | --- | --- |
| `setup` | `/setup` | First-boot wizard steps. |
| `system` | `/system`, `/health`, `/livez`, `/readyz` | Update checks and health probes. |
| `runs` | `/runs` | Inspecting, pausing, resuming, retrying, and cancelling runs. |
| `activity` | `/activities` | The activity feed. |
| `observability` | `/observability` | Traces, spend summaries, and capture settings. |
| `audit` | `/audit` | The audit log and its tamper check. |
| `kill-switches` | `/kill-switches` | Arming and standing down emergency stops. |
| `admin` | `/admin/operations` | Maintenance operations. |
| `onboarding` | `/onboarding` | The getting-started checklist and suggestions. |
| `curator` | `/curator` | Curator shadow-mode output. |

Two tags are visible in the document but are not for you to call. `internal` is machinery the
worker calls on itself, and `forms` is not reachable on a running instance.

## OpenAPI metadata

`GET /api/v1/openapi.json` serves the live OpenAPI document. It is intentionally not listed as an
application endpoint group above.
