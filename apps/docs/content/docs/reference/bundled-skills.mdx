---
title: Bundled skills
description: How bundled skills give agents everyday abilities and guided build paths, and how to find the set shipped by your release.
---

A skill is a capability package an agent can use. Every instance ships with a set of bundled
skills, already installed. You do not have to add these, and you can ask an agent to build more.

Open **Skills** to see the exact set shipped by your release. The screen is the source of truth
because new bundled skills can arrive in an upgrade.

## Core skills

Core skills provide everyday abilities such as researching stored knowledge, creating documents,
and guiding first-time setup. An agent loads one when it matches the current request.

## Forge skills

Forge skills are the guided build paths. They create or update resource types, agents, routines,
skills, and surface components.

## Where they live

Bundled skills are copied into your soul at startup, under `skills/`. Because the soul is a git
repository, every change to a skill is a commit you can read.

Edit one and it becomes yours: startup stops overwriting a skill whose content no longer matches
what was installed, so an upgrade never silently discards your changes.

You never have to edit those files by hand. Ask an agent in chat to change a skill and it edits
them for you, which is what `skill-forge` is for.
