---
title: Bundled skills
description: The ten skills every TulipFarm instance ships with, what each one lets agents do, and where they live.
---

A skill is a capability package an agent can use. Every instance ships with ten of them, already
installed. You do not have to add these, and you can ask an agent to build more.

They arrive in three groups.

## Core skills

The everyday abilities. These are what an agent reaches for when someone asks an ordinary question
about the business.

| Skill | What it lets an agent do |
| --- | --- |
| `business-records` | Inspect schemas, find records, and make verified changes to business data. |
| `knowledge-research` | Research stored knowledge, reconcile sources, and cite the pages it used. |
| `structured-results` | Present lists, metrics, comparisons, and forms as clear structured output rather than a wall of text. |
| `onboarding` | run guided first-time setup and generate a starter soul for a new business. |

## Forge skills

The building abilities. These are how the product builds itself: when you ask for a new resource
type, agent, routine, skill, or component, a forge skill is what does the work.

| Skill | What it builds |
| --- | --- |
| `resource-forge` | A resource type — its fields, links, transforms, and hooks. |
| `agent-forge` | An agent — its persona, model, autonomy, and interface guidance. |
| `routine-forge` | A routine — its triggers, states, retries, and approvals. |
| `skill-forge` | A new skill, or an improvement to an existing one. |
| `surface-component-forge` | A business component that agents can render in a reply. |

## Integration skills

Abilities that only make sense once a provider is connected.

| Skill | What it lets an agent do | Needs |
| --- | --- | --- |
| `github` | Triage issues, work on pull requests, and read repository content. | The GitHub integration |

## Where they live

Bundled skills are files in your soul, under `skills/`, grouped into `core/`, `forge/`, and
`integrations/`. Because the soul is a git repository, every change to a skill is a commit you can
read.

You never have to edit those files by hand. Ask an agent in chat to change a skill and it edits
them for you, which is what `skill-forge` is for.
