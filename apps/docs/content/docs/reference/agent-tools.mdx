Agents receive a Tool set at turn execution time. Tool names are stable snake_case identifiers.
GitHub tools are available only when the GitHub integration is connected.

## How tool calls behave

Tool calls in one model step are batched by effect. If every call is a read, the batch runs in
parallel. If any call writes, the whole batch runs sequentially. Each call has a 30-second timeout.

List-shaped results are truncated to about 20 items for the model, with `total_count` and
`truncated: true` metadata. The UI event keeps the full result for display.

Guardrails wrap every turn in three stages: input before the model sees the message, tool-call
before dispatch, and output before the answer is persisted. Built-in guards are `prompt_injection`,
`content_filter`, and `tool_blocklist`.
