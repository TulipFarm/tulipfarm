---
title: Using TulipFarm
description: Build and run business operations by chatting. Create Resource types, agents, and routines, use the knowledge wiki, and approve agent work. No code required.
---

This is the part of TulipFarm you use every day. You describe what you want in chat, and an
agent builds it, runs it, or answers with it.

Nothing on this track needs a terminal, a code editor, or admin access. If a page here tells you
to open a settings screen you cannot reach, that is a bug in these docs. Everything on this
track is meant to work for any account.
