title: Skills
description: Reusable instruction packs that Agents load on demand and audit before install.
---

A **Skill** is a reusable instruction pack. It gives an Agent task-specific process and references
without loading that material into every turn. Skills follow the agent-skills shape: `SKILL.md` plus
optional reference files.

## Progressive disclosure

Skills load in layers. The name and description are visible so the Agent can decide whether the
Skill applies. The `SKILL.md` body is loaded with `load_skill` when needed. Reference files are
loaded later with `load_skill_reference` only when the Skill asks for them.

That keeps normal turns small while still allowing deep instructions for specialized work.

## Built, bundled, or installed

TulipFarm ships bundled forge Skills such as `resource-forge`, `agent-forge`, `skill-forge`,
`routine-forge`, `surface-component-forge`, and `onboarding`. You can author a new Skill by chat
through `skill-forge`, or install Skills from a git repository through the marketplace flow.

The install flow scans a repository, runs **SkillAudit**, and then installs only after operator
confirmation. Installed Skills are written to `soul/skills/{name}/` and pinned in
`skills-lock.json` with provenance.

## SkillAudit is advisory

SkillAudit is an LLM safety review that reports what the Skill asks Agents to do, suspicious
instructions, and risk level. It is not a sandbox and not an authorization boundary. A low-risk
report does not auto-install a Skill, and an installed Skill still runs with the Agent's available
Tool reach.

Use [Install a Skill](/docs/guides/install-a-skill) for the install flow.
