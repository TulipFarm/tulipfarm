---
title: Self-hosting TulipFarm
description: Install TulipFarm on your own server and keep it healthy. Covers Docker Compose, Coolify, Portainer, Kubernetes, TLS, backups, and upgrades.
---

TulipFarm runs on machines you control. Nothing here depends on a hosted service, and your
business data only leaves the instance when an agent was explicitly allowed to send it.

This track is about the server. It uses a terminal, and it assumes you can reach the machine
TulipFarm will run on. If you are setting up the *product* rather than the server, go to
[Administration](/docs/administration) instead.
