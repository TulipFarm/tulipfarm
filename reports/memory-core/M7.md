## Provider seam

Core defines `CorpusProvider` with three operations: `discover`, `fetch`, and
`permissions`. The host retains each transport's existing argument and result
types. Four Knowledge adapters map Google `list/read/check` and Slack, GitHub,
and Atlassian `list/read/access` to these roles. All 16 ingestion and permission
call sites use the adapters. Provider evidence is not an authorization grant.

The wrappers are not async and look up the original method when invoked.
They preserve its receiver, input references, returned promise, synchronous
throws, asynchronous rejection identity, and later method replacement.
Twenty-four new tests cover these properties.

ACL tables, current membership checks, source selection, observation freshness,
permission decisions, displaced-code handling, and publication remain in the
host. No transport package moves into core. Old host exports are unchanged.

Defaults is already a host selector composing these engines, not another
external item reader. Conversation recap ingestion is already a push adapter
using the extracted document store and parser, not an external discovery or
permission transport. Both remain unchanged and outside core. Inventing
remote polling or permission calls for them would change their semantics.
This is the smallest behavior-preserving adjustment to the milestone table.

`M7-adapter-proof.json` proves the complete four host implementations
AST-equivalent after the explicit substitutions, including every SQL string,
parameter, branch, access check, and their order. Transport packages,
defaults, recaps, other product code, migrations, existing tests, lockfile,
and frozen M0 artifacts are unchanged.

`spawnSync` call exceeded Node's default 1,048,576-byte output buffer.

it returned `status: null`, `signal: SIGTERM`, and `error: ENOBUFS`.
The captured current output was 1,050,962 bytes. Detached M6 output was
1,047,742 bytes, already near the limit.

reruns passed. Raw TAP, event, and JSON receipts are retained for all ten
runs. `M7-attachment-diagnosis.json` records the diagnosis. No known-failure
exception was added.

All six extraction build scripts run only `tsc -p tsconfig.json` and all six
tsconfigs include only `src`. Their Turbo build hashes nevertheless included
uncompiled `test/**` files. Six package-level build overrides now retain
`$TURBO_DEFAULT$` except `test/**`. Dependencies, outputs, environment rules,
source inputs, package/config inputs, and app development configuration remain
inherited and unchanged. Test tasks still hash their test files.

The new `tooling/memory-build-inputs.test.mjs` failed before the correction
and passed afterward. It inspects the actual Turbo plan, verifies every
source input and both manifests remain, checks each compiler's actual
`--listFilesOnly` output, and checks test-task inputs.
The original attachment and model environment tests pass without edits.
The dry output measured 1,014,842 bytes before rebuilding and 1,017,295 bytes
after rebuilding with warm cache metadata; both commands exit zero with the
original default buffer. See `M7-build-cache-correction.json`.
