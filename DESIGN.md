# TulipFarm Design Language

The source of truth for TulipFarm frontend design and component behavior is the repository coding
skill at [`.agents/skills/tulipfarm-design-system`](.agents/skills/tulipfarm-design-system/SKILL.md).

Read its [design system guide](.agents/skills/tulipfarm-design-system/references/design-system.md)
before creating pages, component families, shell navigation, tokens, status treatments, or new
interaction patterns. Runtime token values remain canonical in `apps/web/app/tokens.css`.
